# GUIA DE PUBLICAÇÃO — PORTAL DO DIREITO EUTÍMICO

O pacote é estático. Publique `index.html`, `portal.css`, `portal.js`, a pasta `dados/`, `manifest.webmanifest`, `robots.txt` e `404.html`.

## Antes da publicação institucional definitiva

1. Confirmar o HEAD do repositório.
2. Executar a Auditoria técnica no próprio Portal.
3. Atualizar o Livro de Alterações para o marco jurídico desejado.
4. Revisar o Código Eleitoral republicado.
5. Manter pendências ambíguas explicitamente sinalizadas.
6. Inserir o arquivo gráfico correto do brasão oficial.
7. Definir a URL canônica.
8. Testar desktop e mobile.

O Portal pode ser hospedado em GitHub Pages ou qualquer servidor estático. Ele consulta o GitHub para obter o acervo atual.
